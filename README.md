# 珊瑚礁产卵 · Coral Reef Spawning

一个面向小学生的珊瑚礁产卵交互实验室。用操作实验、剖面探索和答题，理解珊瑚为什么要等「满月后的夜晚」才产卵。

## 板块

1. **四个条件实验室**（主板块）：季节、水温、月相、时间四个控制器，四灯全亮触发同步产卵。内含 6 个彩蛋（白化、错过窗口、冬天、透视产卵房、大产卵现场、黄金时刻）。
2. **精卵束剖面探索**：切开精卵束，看黏液外膜、卵细胞、精子团与精子结构。
3. **卵细胞的生存装备**：浮力脂滴、卵黄口粮、防晒 MAA、可选共生藻。
4. **全球产卵时间地图**：9 个礁区的产卵月份对比。
5. **精卵束的漂流旅程**：动态水柱场景，从释放、上浮、受精、分裂、幼虫到附着变态。
6. **浅水 vs 深水**：紫外线下的存活率差异实验。
7. **为什么是满月**：月相与潮差的联动。
8. **防晒霜与珊瑚**：白化归因判断。

## 玩法

- 探索与彩蛋累积「精卵束银行」，攒到 10 万亿触发终极动画。
- 每个板块结束可选简单/中等/困难三档答题。
- 进度自动保存在浏览器本地。

## 本地运行

直接用浏览器打开 `index.html` 即可，无需构建。

## 技术

纯 HTML / CSS / 原生 JavaScript，动画用 SVG + CSS，无第三方依赖。
